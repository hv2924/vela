# Contributing to Vela

Thank you for your interest in contributing to Vela.

Vela is an experimental programming language designed to make program intent explicit, make unsafe behavior difficult, and give the compiler enough semantic information to generate efficient code.

Vela is currently at version `0.0.1`, so the language and compiler are still evolving.

## Getting Started

### Requirements

- Node.js
- npm
- Git
